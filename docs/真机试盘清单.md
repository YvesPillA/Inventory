# 出发前真机试盘清单（0.2.2）

实际手机尚未连接，以下项目由用户在自己的手机与典型标签上完成；模拟器通过不代表现场相机、声音或振感已验证。

- [ ] 先在旧版保存完整备份并复制到电脑；同签名覆盖安装0.2.2，确认国家、仓库、配件和整机保留，不卸载旧版。
- [ ] 开飞行模式，手动录入纯数字BOM、字母数字混合BOM、前导零和最长SN；检查两段SN输入及键盘出现后保存按钮。
- [ ] 使用真实相机试扫小字、反光、斜角及模糊标签；检查对焦、补光、候选选择和编号修正，确认O/0、I/1和前导零。
- [ ] 开关震动与声音并点两种试提示；分别保存正常记录和重复SN，检查节奏明显且不会重复保存；测试手机静音状态。
- [ ] 从标准CSV导入少量合成记录，核对数量预览与目标仓库；改名后再选择同内容文件，确认会提示既往导入。
- [ ] 在测试仓库演练一次重复导入，再整批撤销；核对数量和导入历史退回，其他新记录保留。
- [ ] 在测试国家演练删除最后一个仓库/国家，再从仓库选择页撤销；检查记录恢复。涉及真实库存前不要直接用真实国家演练删除。
- [ ] 关闭并重开软件，核对库存、反馈开关和恢复点仍在。
- [ ] 导出Excel并复制到电脑检查件数、台数、损坏和待核查；再保存完整JSON备份，在测试环境回读核对。

收工后把完整备份复制到电脑或其他位置。本机恢复点最多五次且受容量限制，不能代替异地备份；旧版及换机前CSV导入历史不包含在新手机的防重复提醒中。
