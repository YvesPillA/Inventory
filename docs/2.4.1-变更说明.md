# 2.4.1：中文 / English

- 首次启动选择中文或 English，旧版升级后第一次启动同样选择；设置中随时切换，选择保存在本机。
- 界面、扫描核对、错误提示、备份与恢复说明支持中英文。切换语言保留盘点表单的未保存输入，不修改已有库存。
- Excel 工作表、表头、状态、单位、CSV ZIP 内文件名、说明和下载模板按发起导出时的语言生成；文件选择器期间进程重建仍使用该语言。
- 标准 CSV 导入接受中文、英文或混合表头，列顺序固定。类型与状态支持中英文值，英文大小写不敏感。界面语言不限制文件语言。
- 中英文同义状态统一转回已有数据库值；等价 CSV 的重复导入指纹一致。编号大小写、前导零、备注、SN 冲突处理及校验规则保持一致。
- 完整 JSON 备份继续使用旧格式，数据库 schema 仍为 4；中英文环境均可导出并恢复，不把语言偏好写入库存备份。
- 新增 [英文说明](../README.en.md)，支持在应用内下载当前语言的模板。模板只有表头，不含示例库存。

## 导入字段

| 中文表头 | 英文表头 | 固定取值 |
| --- | --- | --- |
| 类型 | Type | 配件 / Part / Parts；整机 / Machine |
| BOM | BOM | 原有编号规则 |
| SN | SN | 配件留空；整机填写含横线的完整 SN |
| 数量 | Quantity | 正整数；整机必须为 1 |
| 状态 | Condition | 正常 / Normal；损坏 / Damaged；待核查 / Pending verification / Pending |
| 备注 | Note | 保留原文，按标准 CSV 规则处理逗号、双引号和换行 |

只支持 UTF-8 标准 CSV 模板导入。日常报告 CSV、XLSX 和 ZIP 不作为模板导入；换机恢复使用完整 JSON 备份。

## 升级与历史数据

Android versionCode 为 7，versionName 为 2.4.1。原有 applicationId 不变，使用原签名才能覆盖旧版安装。升级前把完整备份复制到电脑，不要先卸载。

国家、仓库名称、备注、OCR 原文及原来保存的历史操作描述均保留原文；界面切换不会翻译或改写这些历史数据。语言选择仅保存在当前手机，换机时重新选择。
