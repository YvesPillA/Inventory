# 盘库助手 0.2.3

本版实现两项：OCR 易混字符复核、每日完整备份与换机恢复入口。versionCode 5，数据库保持 schema 4，沿用原签名覆盖安装。

## OCR 核对

- 显示本次取景区域的局部照片，双指放大/拖动、重置。
- 按位置列出 0/O/o、1/I/i/l、8/B/b 选项，由用户点选，只替换一位；保留前导零、大小写与 SN 横线。
- 页面重建后最终输入和照片仍对应，确认后返回编号与原识别文字。
- 正常退出或重扫清除临时照片，异常中断的过期文件下次扫描清理；不添加库存照片附件或导出照片。

## 每日完整备份

- 默认开启，按手机当前时区每日首次使用时保存当时库存。启动、返回应用及写操作前检查，同日重开复用已有有效文件。
- 立即备份可保存当前最新状态；在设置关闭每日生成，手动保存仍可用。
- 最多保留最近七份。新文件写入、同步并回读校验成功后才清理旧文件；写入失败保留旧副本、显示原因，盘点可继续。
- 处理导出区、设置及仓库选择页均可看时间列表、另存指定快照、分享或预览合并恢复。
- 另存请求先持久化选中快照；文件选择器导致进程重建时仍可完成。分享使用 Android 内容 URI 与读取授权，连续分享不同备份保留先前接收端的文件副本。
- 与原完整 JSON 格式兼容，所有国家/仓库、作废、待核查和历史都保留，支持带到新手机恢复。

## 使用说明

每天首次使用的备份保存当时状态，当天新增内容收工点“立即备份”。每次手动保存也占一份，最多七份。应用内文件随卸载删除，需另存到电脑或其他位置；分享是否成功应在接收端核对。

原合并恢复规则保持：相同记录跳过、同 ID 内容冲突整批取消、新增重复 SN 转作废。恢复点、CSV 导入历史、提示偏好和扫描照片不进入便携备份。单份仍最多32MiB。
