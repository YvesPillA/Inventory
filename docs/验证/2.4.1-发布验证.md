## 正式包流程

Android 9 / API 28、360 × 720 模拟器中卸载原测试应用，首次安装本次正式 APK。测试运行器单独使用同一发布签名，不放入交付目录。以下 **8 项通过**：

- `BilingualWorkflowTest` 3 项：首次语言选择、重建后记住语言、切换保留库存和输入、导出语言持久化。
- `OcrInstrumentedTest` 2 项：随包原生 OCR 模型读取与编号处理，确认压缩原生库安装后可加载。
- `ManualWorkflowTest` 2 项：标准 CSV 指定仓库导入及重复 SN 作废；选中时间的备份回读保持原快照。
- `ExportRecoveryInstrumentedTest` 1 项：ViewModel 销毁后继续导出原备份快照。

随后使用 `adb install -r` 实际覆盖安装同签名正式包，对比记录页文字：整机 `OLDMODEL / AA-001`、数量 1、仓库和界面语言均保留。
