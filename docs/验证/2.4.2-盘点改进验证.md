# 2.4.2 盘点改进验证

版本：2.4.2 / versionCode 8。最低 Android 8.0，数据库 schema 5，JSON 备份格式 v2（读取兼容 v1）。

## 功能与兼容

| 范围 | 结果 |
| --- | --- |
| 配件 BOM | 手输与扫描确认回填后更新同一个查询面板；只查询本仓有效配件，显示完全相同 BOM 的条数/总数量及模糊相关记录；其他仓、整机、作废不混入 |
| 整机 PN | 单框手输、单次/持续扫描，支持字母数字和多段横线，保留大小写/前导零；记录展示/搜索/编辑、审计、报表、导入、备份及撤销均保留 PN |
| 整机选填 | 正常/损坏整机只需有效 SN；BOM、PN 可空；原 SN 格式和全库唯一约束保留，待核查沿用原缺号草稿规则 |
| 备注扫描 | 配件和整机的“更多”均可扫描；整段识别并保留符号/换行，核对框可多行编辑，不套编号格式；最多4000字，确认回填后手动保存 |
| 双语与文件 | 中文/英文界面、校验、报告、模板同步；新增末列 PN 的7列模板兼容旧6列，混合表头和值仍可导入；无 PN 文件保留原重复导入指纹 |
| 数据升级 | schema 4 → 5 增加 PN/来源/原文，旧值为空；兼容 schema 1–3 升级和旧审计；新备份完整保存 PN，旧备份读入时补空 PN |
