# 盘库助手操作说明

## 1. 安装、升级和进入仓库

手机要求 Android 8.0 或以上。安装文件及签名状态见 [下载说明](../README.md#下载与安装)，按系统提示允许安装。

已有旧版时，先保存完整备份并复制到电脑，然后直接安装同签名正式包覆盖升级，**不要卸载旧版**。卸载会删除应用内数据与本机备份。

首次启动先选择中文或 English，之后可在设置切换，库存及未保存盘点输入保留。随后选择国家和仓库，点击“进入仓库”。没有国家时点“新建国家”，再在该国家下点“新建仓库”。国家不限，整个过程离线可用。进入后底部有“盘点、记录、处理、设置”四页。

“盘点、记录、处理”顶部显示一行国家/仓库；每次保存前先核对。新建或切换国家、仓库只在启动页和“设置”中操作，名称也可在设置修改。修改名称保留记录归属。存在未保存输入时，切换仓库会先询问是否放弃；切换后退出保留 BOM 状态。

日常操作不再选择任务或填写库位，旧版本的这些信息仍留在完整备份中兼容。

## 2. 配件：BOM 加本次数量

在“盘点”选“配件”，填写或扫描 BOM，再输入**本次清点数量**，单位为件。箱、包请先换算成件。BOM 只接受 1～14 个英文字母或数字，前导零、大小写照标签原样保存。

输入或扫描回填 BOM 后，下方显示本仓是否已有完全相同的 BOM、条数与合计数量，并列出相关配件的状态、数量、备注和时间；只查本仓有效配件，大小写不同的近似项作为相关记录展示，不自动合并。

状态默认正常；需要标记损坏、待核查或填写备注时，点“更多”，完成后返回录入页。下方已有记录可独立滚动，保存按钮固定在底部。键盘出现时会收紧布局；切换类别、使用更多或调整保留 BOM 开关，可先收起键盘。

点“保存这一条”，看到成功提示后再盘下一项。同仓库、同 BOM、同状态再次保存，选择“添加到已有数量”会把本次数量加到最早的已有条目；选择“新增条目”会另存一条。两种方式汇总数量相同，例如 10 件加 5 件均汇总为 15 件。不同状态始终分开。如果原来的 10 件应为 8 件，应到记录页修改原记录，不要再追加 8 件。

“清空”只清除当前未保存的输入，不删除已保存记录。

## 3. 整机：SN 必填，BOM、PN 选填

在“盘点”选“整机”，只填有效 SN 即可保存，BOM、PN 均选填，每台一条，数量自动为 1。PN 可手输或独立扫描，接受字母、数字及多段横线，例如 `000-aB-02-C`，最多100位，不自动插入横线。整机输入区可滚动，保存按钮固定。

手动输入 SN 时分别填写“SN 前段”和“SN 后段”，**不用输入中间横线**，软件自动组成 `前段-后段`。两段都只允许英文字母或数字，合计最多 14 位。例如前段 `ABCDEFG`、后段 `1234567`，保存为 `ABCDEFG-1234567`，含横线共 15 位。

同型号连续盘点可开启“连续录入时保留 BOM”。保存后只保留 BOM，清空 PN、SN 和备注；换型号先改 BOM，切换仓库后重新确认开关。修改已有记录时不使用连续新增模式。

非空整机 SN 在**所有国家、所有仓库的非作废记录中唯一**，待核查记录已填写的 SN 也参加检查。再次新增完全相同的 SN 时先提示，确认后将本次新记录转入作废页，已有非作废记录保持。批量操作统一列出重复 BOM 和 SN。修改已有整机为被占用的 SN 时会阻止修改，原记录保持。只差大小写的近似 SN 会提示核对，确认后仍按原样保存，不自动统一大小写。

## 4. 扫描印刷编号

“扫描 BOM”、“扫描 PN”和“扫描 SN”读取标签上印刷的数字、英文字母和横线，暂不解析条形码、二维码中的内容。

1. 首次打开扫描时允许相机权限。
2. 可选“单次识别”或“持续识别”。单次把目标编号放入取景框，尽量避开日期、订单号等其他文字；持续模式可放入多行，操作见第16节。
3. 光线不足时补光，反光时调整角度；设备没有补光灯时会提示。
4. 点击识别；核对页显示本次取景区域的标签照片。可双指放大、拖动，点“重置照片”恢复；多个候选需点选。
5. “最终 BOM/PN/SN 编号”可直接编辑。“易混字符逐位核对”标出容易混淆的位置，点击位置后选择数字或大小写字母，只替换这一位。标记不代表识别有误，不要把标签上本来正确的字母全部换成数字。空格、不同横线等修正会展示原文及修正信息。
6. 确认填入，回到盘点页再次核对，最后保存。扫描出的 SN 会填入前、后两段，PN 完整填入单个输入框，配件 BOM 回填后立即刷新已有记录。

配件和整机均可在“更多”点击“扫描备注”。将需要的多行文字放入较大的取景框，识别后整段核对、编辑并确认填入；保留数字、字母、常用符号和换行，不套用编号格式，最多4000字。确认会替换本次未保存的备注，保存记录后才写入库存。

镜头连续对准同一标签不会自动新增记录或累计数量。`O/0`、`I/1`、`B/8` 等以真实标签为准，前导零和大小写保持。扫描页重建后保留照片及最终输入；照片不可用时明确提示并允许重扫。正常退出扫描或重扫清除临时照片；进程异常中断的过期照片下次扫描时清理，不会附加到库存记录或完整备份。

真实手机相机、真实标签尚未完成现场验证。出发前应使用自己的手机试扫，而不是直接依赖模拟器测试结果。

## 5. “正常”与“作废”记录页

“记录”包含两个独立页签：

| 页签 | 包含什么 | 可以做什么 |
| --- | --- | --- |
| 正常 | 当前仓库全部非作废记录，包含正常、损坏、待核查三种状态 | 搜索、筛选、修改、作废、清空 |
| 作废 | 当前仓库已作废记录，可保留重复 SN | 搜索、筛选、单条还原、删除、清除全部作废 |

搜索支持 BOM、PN、SN 和备注；筛选有全部、配件、整机、待核查。“正常”页的名称表示未作废，并不表示其中货物都处于正常状态。

标签缺号或暂时无法确认时，在“更多”选择“待核查”。缺失编号可留空，但至少填写一个编号或备注；非空编号仍须符合格式，配件数量仍为正整数。待核查不计入已确认数量，Excel/CSV 单列。复核后修改该条，补齐编号，把状态改为正常或损坏。

在正常页点“多选”或长按条目进入勾选模式，可逐条勾选或全选当前筛选结果，再批量作废。至少两条同 BOM、同状态配件可以“合并配件”，合计数量保存在最早条目，来源条目消耗，备注和合并来源留档；整机、不同状态以及缺少 BOM 的待核查配件不能这样合并；缺号配件在添加数量模式下也会保持分开。

点“作废”并确认后，该条不再计数，但记录和修改历史仍保留。作废整机的 SN 可以重新录入。需要还原时，在作废页点“还原”；如果 SN 已被另一条非作废整机占用，该条继续保留在作废页。配件还原时若存在同 BOM、同状态非作废配件，可选择“添加到已有数量”或“新增条目”；选择相加会消耗原作废条目，避免再次还原重复加数。

## 6. 删除与批量清空

| 操作 | 确认次数 | 删除范围 |
| --- | --- | --- |
| 作废页单条“删除” | 1 次 | 选中的作废记录及其修改历史 |
| “一键清除作废” | 1 次 | 当前仓库全部作废记录及其修改历史 |
| “一键清空正常” | 2 次 | 当前仓库全部非作废记录及其修改历史，包含配件、整机、正常、损坏、待核查 |

批量清空**不受当前搜索关键词和筛选条件限制**，会处理当前仓库对应页的全部记录；其他仓库不受影响。清空正常不会清除作废，清除作废不会清除正常。

删除后不在作废页保留，可在最近恢复点中撤销。以前导出的备份文件可能仍保留这些记录，后来重新导入旧备份可能再次恢复；新备份不包含已经删除的记录。需要留档时请在清空前保存完整备份。

## 7. 导出和备份

在“处理”页切换到“导出”。

“导出 Excel 明细与汇总”和“导出 CSV 压缩包”只导出**当前仓库**，包含该仓库全部历史有效记录，不按旧任务分开。日常导出不含任务、库位列。

Excel 有盘点说明、配件明细、配件汇总、整机明细、待核查五页。正常、损坏按状态分别汇总；待核查独立列出，不计正式数量；作废不进入日常导出。相同仓库、BOM、状态的旧记录合并汇总。

CSV ZIP 含配件明细、整机明细、待核查三份 CSV 和导入说明。CSV 无法指定单元格类型，导入 Excel 时须把 BOM/SN 列设为文本，保留前导零；日常优先使用 Excel 文件。

“保存完整备份”保存**所有国家和仓库**的现存记录、作废记录和修改历史，保留旧版任务及库位字段以兼容。备份不受当前仓库限制，已删除的记录和相关历史不包含在新备份中。

用系统文件选择器指定保存位置，成功后复制到电脑或其他位置。手机中的另一个文件不能防止手机丢失；界面显示成功保存，不代表已经完成异地备份。

## 8. 恢复备份与旧版升级

在“处理 → 导入”、启动页“从备份恢复”或设置“从备份合并恢复”选择 JSON 文件，查看仓库和记录数，再确认“检查并合并”。同一份相同备份重复导入不会重复增加数量。损坏文件、同 ID 内容冲突会取消整个合并，原有数据不变。新增的重复 SN 整机转入作废页，确认前和结束后统一提示重复 BOM、SN；相同备份再次恢复不会重复增加这些记录。

同名国家可勾选“将仓库加入现有国家”；同名仓库选择“合并到现有仓库”或“改名后加入”，新名称不能与该国家已有仓库重名。合并时，同 BOM、同状态的配件选择“新增条目”或“添加到已有数量”，整机仍按全库 SN 去重。确认前取消不改库存，合并失败整批回滚；来源记录和历史归档保留，相同备份再次导入不重复加数量，重要操作可通过本机恢复点撤销。两种界面语言使用相同规则。

两种旧数据处理方式不同：

- **同签名旧库覆盖升级**：数据库升级到 schema 5，旧记录补空 PN。历史不同任务下完全相同的非作废 SN，每个保留最近修改的一条，其余自动作废并写入完整前后审计；升级提示说明处理数量，可到作废页检查。全部记录仍保留。早期另一签名的安装包按下载说明先安排备份迁移。
- **导入普通旧备份**：如果新增记录的 SN 与现有记录或文件内更早的记录重复，已有记录优先，新增重复整机转入作废；其他有效记录正常合并。

较旧备份与当前同一条已修改记录不同，也会报冲突，没有强制覆盖按钮。迁移到新手机应使用最新完整备份。2.4.2 写入保存 PN 的格式 v2，仍能读取旧 v1；新备份需用 2.4.2 或以后兼容版本恢复。

## 9. 文件导入与 CSV 模板

在“处理 → 导入”点“选择盘库或备份文件”，可直接选导出的 Excel、CSV 压缩包、单份报告 CSV、标准 CSV 或完整 JSON 备份。中英文文件可交叉导入，不需要先切换界面语言。

Excel/CSV 仍选择目标仓库和同 BOM 配件处理方式，预览后确认；Excel 只取明细，跳过配件汇总与说明。旧版没有 PN 的报告仍可使用。JSON 则直接预览备份仓库和记录数，按原仓库检查并合并，不套用表格目标仓库。页面说明已精简并放到最底部。

在同一页面也可下载标准模板，保存到手机或电脑。模板只有表头，不含示例库存。支持以下中文表头，或按相同顺序使用 `Type,BOM,SN,Quantity,Condition,Note,PN`；可混用中英文表头，英文不区分大小写。旧版没有末列 PN 的六列文件仍可导入：

```csv
类型,BOM,SN,数量,状态,备注,PN
```

| 列 | 填写规则 |
| --- | --- |
| 类型 | 配件 / Part / Parts，或整机 / Machine |
| BOM | 1～14 个英文字母、数字，保留前导零和大小写；整机可留空 |
| SN | 配件留空；整机填写完整 `前段-后段`，不计横线最多 14 位 |
| 数量 | 1～1000000000 的整数；整机固定填 1 |
| 状态 | 正常 / Normal、损坏 / Damaged、待核查 / Pending verification / Pending |
| 备注 | 选填，最多 4000 字；待核查缺号时至少有一个编号或备注 |
| PN | 整机选填，最多100位字母数字，可用多个横线连接非空分段；配件留空 |

例如一条配件可以填类型“配件”、BOM“000123A”、数量“12”、状态“正常”，SN 和备注留空；整机则填类型“整机”、BOM“000123A”、SN“0001-02AB”、数量“1”、状态“正常”。这些仅是说明示例，不会预置到下载模板或库存中。

用 Excel 编辑时，**填写编号前**将 BOM、PN、SN 列设为文本，再保存为“CSV UTF-8（逗号分隔）”。不要保存成 XLSX 工作簿，也不要把日常导出的明细 CSV 直接当成标准模板。CSV 直接打开可能丢失前导零，丢失后导入无法自动补回。

回到“处理 → 导入”，选择国家和仓库，点“选择为导入目标”，核对下方目标名称；这个选择不改变盘点页的当前仓库。选择“添加到已有数量”或“新增条目”，读取标准 CSV 文件，再点“预览并确认导入”。长预览可在弹窗内上下滚动，确认按钮保持在下方。支持 UTF-8 BOM、CRLF/LF 换行和标准双引号转义；备注中的逗号、换行需要双引号包围，内部双引号写成两枚。空行忽略，上限 8 MiB、10000 条数据。表头不符、格式损坏、编号或数量错误会显示行号并取消整批，先修正文件后重试。

导入确认框列出本批重复整机 BOM、SN；确认后重复整机进入作废页，批次结束后统一提示，不计入正式数量；其他记录正常导入。CSV 是追加导入，重复导入同一文件会再次追加记录；不要反复导入来修正数量，修改应到记录页操作。JSON 备份恢复按记录 ID 合并，CSV 则按所选方式添加库存，两者用途不同。

## 10. 删除国家、仓库与合并仓库

先在设置切换到要操作的国家/仓库。“删除当前仓库”会删除这个仓库的全部正常、待核查和作废记录及修改历史；“删除当前国家”会连同其全部仓库和记录删除。两次确认都显示国家、仓库名称和记录条数，取消不会删除。删除最后一个仓库后返回仓库选择页。

“合并当前仓库”只能选同国家的目标仓库。选择配件重复处理方式，两次确认均显示来源和目标。确认后全部记录迁移到目标仓库，来源仓库删除；作废保持作废，同 BOM 不同状态保持分开，非作废整机 SN 仍全局唯一。选择相加会消耗已并入的来源配件条目。

删除国家/仓库可在最近恢复点整批撤销，请仍先保存完整备份；以前的备份仍可能重新恢复这些记录。

## 11. 导入前核对数量与防重复提醒

读取文件后显示文件名和本次数量预览：正式配件增加件数、正式整机增加台数、文件中待核查行、重复整机作废条数、配件并入已有条目行数、新增条目以及导入后本仓正式合计。切换仓库或重复处理方式时预览随之更新；合并数量超上限时无法确认。待核查不计入正式数量，但仍正常保存。

软件按解析后的文件内容识别重复导入，改名、UTF-8 BOM 和记录换行变化仍可识别。出现既往导入记录时，核对时间、仓库和行数，再决定是否“仍要重复导入”；确认后会再次增加库存。只有成功提交的导入才记入历史。历史从本机0.2.2开始记录，旧版本导入和其他手机的导入无法补齐，仍需人工核对。

## 12. 整批撤销重要操作

CSV/JSON导入、仓库合并、勾选配件合并、作废还原、批量作废、删除和清空前自动保存本机恢复点；操作和恢复点一起成功提交，失败时不改变库存。设置中点“撤销重要操作”，选择具体文件/操作和时间，确认后整批退回。删除最后一个国家/仓库后，仓库选择页也有这个入口。

只撤销所选操作涉及的记录，后来新增的其他记录保留；相关数量、名称或历史后来有改动时，会停止撤销并提示，避免覆盖后续工作。可先撤销后续相关操作再重试。恢复整机时若SN已被其他新记录占用，恢复的重复整机进入作废页并统一提示。已经撤销的点不能再次撤销。撤销CSV导入时同时退回对应的导入历史。

最多保留最近五次重要操作，达到容量限制时更早的点会提前清理。恢复点及CSV导入历史仅在本机数据库中保存，关闭重开仍在；它们不包含在导出的完整JSON备份中，也不能防止手机丢失或卸载。新备份不含已删除的库存，但较早恢复点可能暂存这些数据，直至被清理。

## 13. 震动和声音

设置中“保存震动”默认开启，“提示声音”默认关闭，可分别关闭或打开。点击“试成功提示”“试重复提示”预览；成功保存给出短反馈，重复SN使用较长的不同反馈，批量重复只提示一次。声音遵循手机静音和通知音量；关闭反馈或设备没有相应硬件不会影响保存。升级及重开保留开关选择；实际声音、振感仍需在自己的手机上体验。

## 14. 出发前试盘

用真实手机和典型标签测试纯数字、混合编号、最长 SN、前导零、反光和模糊情况。开启飞行模式，录入配件及整机，重复录入一台验证全库 SN 检查；关闭重开后核对数据，再把 Excel 和备份复制到电脑检查。

同时演练一次作废、还原冲突、删除确认和备份回读。每天收工保存 Excel 和完整备份。升级直接覆盖安装；更换手机或卸载前先把备份带走。

真机逐项核对清单见 [真机试盘清单](真机试盘清单.md)。

## 15. 每日自动完整备份

设置中的“每日自动完整备份”默认开启。软件按手机当前时区，在每天首次使用时保存当时的全部国家、仓库、库存、待核查、作废及修改历史；启动、返回软件和写操作前会检查。当天重开不会重复保存。它保存的是当时的状态，当天新增内容需收工点击“立即备份”或手动导出完整备份。

最多保留最近 7 份。手动“立即备份”也占一份；只有新文件完成写入、回读与 SHA256 校验后才清理旧文件。最近时间指本机备份生成时间，不能据此认定文件已在其他设备保存。备份失败显示具体原因，不阻止继续盘点；修复存储问题后可点击“立即备份”重试。关闭每日自动备份保留已有文件，也仍可手动备份。

在“处理 → 导出”、设置或仓库选择页点击“查看本机备份”，按时间选择：

- **另存为**：通过系统文件选择器保存选中时间的备份副本，不会把当前最新库存替换进去；可放到能传给电脑或新手机的位置。
- **分享**：打开安卓分享面板，自行选择接收应用。软件只提供文件，分享是否成功需到接收端核对。
- **恢复**：先预览仓库和记录数，再“检查并合并”。相同记录跳过，同 ID 内容冲突整批停止，新增重复 SN 转作废。它遵循原 JSON 合并恢复规则；需要退回某次近期操作时仍使用“撤销重要操作”。

换手机时，把备份文件带到新手机，安装应用后在仓库选择页“从备份恢复”。本机自动文件随卸载删除；手机损坏或丢失时需要已经另存到其他设备的副本。新备份不含已删除记录，较早备份可能仍保留它们。

自动文件使用原完整 JSON 格式（单份最多 32 MiB），与旧版导入兼容；不包含最近五次恢复点、CSV 导入历史、提示偏好或临时扫描照片。全程不需要应用账号或联网权限。

## 16. 多行持续识别

在盘点页点“扫描 BOM”或“扫描 SN”，再切换“持续识别”。软件记住上次选择，下次打开扫描可继续使用。

把多行编号完整放进大取景框，停稳片刻。符合当前 BOM/SN 格式、连续识别稳定的结果会显示边框和可点击标签。标签编号1、2、3对应下方列表的行次，按画面上下顺序排列，不把不同物理行拼接；重复文字位于不同行也各有一条。贴着取景框边缘的文字可能被截断，请把整串编号移入框内。

点画面标签或列表行，冻结该结果对应的照片并进入核对页。核对前导零、大小写、横线，可用原照片放大与逐位替换，再“确认并填入”。扫描 SN 自动填进前、后两段；回到盘点页最后保存。持续取景、暂停和点选都不会自行新增库存。

画面上标签留有点击间距，原编号处的边框和连线帮助对应位置。多行过密时，部分点击标签留在下方列表，**列表保留全部结果，可上下滑动**，无需挤着点击小字。

手抖、反光或编号密集时，可先点“暂停画面”，停下来选；点“继续识别”清除旧结果并重采集。运行较慢时会自动暂停在本次照片，并说明原因。标记已移走或被新编号替换时，旧点击会提示重新选择，不会默默改成另一行。

切到单次模式会清除实时标记，使用原来的识别按钮。切后台、旋转或重新进入扫描时会重新采集实时结果；已经进入核对页时仍保留照片与编辑内容。持续画面仅在内存中识别，只有点选核对时暂存对应照片，沿用原临时照片清理规则。

## 17. 开发模式与诊断

软件从启动开始在本机记录操作，不需要先进入开发模式。选完文件会显示读取进度；初始化或自动备份忙时先等待，读取完成自动定位到预览和确认按钮。只有确认后才会写入库存。

需要排查时，在设置最下方的版本文字连续点击六次，前五次没有反馈，第六次弹出开发密钥验证；输入私下约定的密钥进入。关闭后再次进入需重新验证，输入内容不保存、不记入日志。

开发模式提供全部/警告/错误筛选、文字搜索、刷新、设备信息、导出或分享诊断包、清空日志。界面显示最新 300 条匹配记录；完整保留记录在诊断包内。日志按容量滚动，最多四份、合计约 2 MiB，重开保留，清空或卸载删除。

复现一次问题后再导出 ZIP 发给开发者。它包含设备/版本/语言/存储信息、操作记录、错误堆栈、本应用进程可读取的 logcat；Android 11 及以上还尝试读取本应用最近的退出原因。应用操作记录含文件名、来源提供器、大小、读取行数、等待与完成/失败状态。库存仅提供数量统计，诊断导出不复制库存明细。完整库存迁移仍使用原完整 JSON 备份。

日志清空有单独确认，只处理日志，不改库存、备份和恢复点。密钥及本地验证配置不包含在诊断包中。
