# 盘库助手界面设计说明

对象：一人携带安卓手机在仓库连续盘点。主要动作是确认当前仓库、输入或扫描编号、保存、继续下一条。

## 页面与导航

首次启动先选择中文或 English，设置中可随时切换；已选择语言后启动显示“选择盘点仓库”：选择或新建国家，再选择或新建仓库，点“进入仓库”。也可从此处恢复备份。进入后底部固定四个入口：盘点、记录、处理、设置。

盘点、记录、处理顶部显示一行国家/仓库，使用深蓝底和清晰文字。选择、创建国家和仓库集中在启动页与设置页，业务页不展开管理表单。设置还包含修改当前名称、恢复备份和编号规则说明。

日常界面移除任务和库位，主页面围绕当前仓库工作。旧版兼容字段保存在底层数据和完整备份中。

## 盘点录入

配件为 BOM＋数量，下方空余区域显示当前 BOM 是否已有有效记录，并提供可滚动的相关记录列表；手输和扫描共用同一输入状态。整机为可选 BOM、可选 PN 和必填 SN 前段/后段，只有 SN 自动补中间横线；PN 为单个完整输入框。BOM、PN、SN 各有扫描按钮。整机输入区域可滚动，保存按钮固定在底部，避免小屏/键盘遮挡。

状态默认正常；状态选择与备注放在可滚动的“更多”弹窗中，备注旁提供扫描入口，核对页支持多行文字及自由符号。整机提供“连续录入时保留 BOM”开关。保存按钮位于底部固定操作行，旁边“清空”只处理未保存输入；编辑时显示“保存修改”和“取消”。

键盘出现或可用高度较小时收紧行距、隐藏次要信息及底部导航，保留编号输入和保存操作。收起键盘后恢复类别切换、更多、保留 BOM 开关及仓库数量概览。布局同时避开系统栏和软键盘。

## 记录管理

“正常”和“作废”使用独立页签。“正常”页表示所有非作废记录，包含货物状态正常、损坏、待核查；页内有文字解释，避免误认为只有正常状态。

两页均保留 BOM/PN/SN/备注搜索和全部、配件、整机、待核查筛选，并显示可见数量/该页总数量。记录卡片依次呈现类别与数量、状态、BOM、PN、SN、备注和修改时间。

正常记录提供修改、作废；作废记录提供还原、删除。还原遇到全库 SN 冲突，弹窗展示已有记录所在仓库及 BOM，并明确该条仍保持作废。

单条永久删除和“清除本仓作废记录”各一次确认。“清空本仓正常记录”两次确认，明确国家/仓库和实际条数。确认文案说明清空覆盖当前页全部类别与状态，不受搜索、筛选影响；其他仓库不受影响。永久删除后相关审计也删除，不能从作废页还原。

## 导入、导出与恢复

导入页上方优先放模板下载和“选择盘库或备份文件”，随后选择目标仓库与同 BOM 配件处理方式，文件读取后预览数量并确认。说明合并为一个精简文本块，位于页面最底部。Excel/CSV 支持中英交叉导入；选择 JSON 自动转入原仓库合并确认。

处理页的导出区优先提供当前仓库 Excel，随后提供 CSV ZIP；完整备份单独分区，标明范围为所有国家和仓库。日常导出移除任务、库位列；待核查独立列出，不混入已确认数量。

文件通过安卓系统文件选择器保存。界面显示最近成功保存时间，并提醒把文件复制到电脑或其他位置。恢复前展示仓库和记录数量，确认后事务合并；发生冲突时整次取消。

旧版数据库升级自动处理历史重复 SN 时单独提示：每个 SN 留下最近修改的一条，其余移入作废页，记录与完整修改历史保留。普通旧备份合并时相同记录跳过、同 ID 内容冲突整批取消；新增重复 SN 转入作废，不覆盖已有记录。

## 视觉与反馈

颜色：仓库栏深蓝 `#123E52`，主操作蓝 `#1463C7`，成功绿 `#0B7B77`，待核查/提醒橙 `#995010`，背景 `#F4F7FA`，纸面白 `#FFFFFF`，正文深色 `#193543`。

中文采用安卓系统无衬线；主要标题约 22sp，字段与正文以可读字号呈现。编号采用等宽字体。颜色辅助状态判断，正常、损坏、待核查、已作废均使用明确文字。

保存、识别、导出等操作有进行中状态和明确结果，忙碌时阻止重复提交。扫描只给候选值，修正后确认填入；镜头连续识别不会自动新增记录。校验失败保留输入，显示具体字段错误。

实机还需验证窄屏、软键盘、字体缩放和真实标签相机效果；这些设计说明不代表现场验证已经完成，实际结果见验收记录。

## 扫描核对与自动备份

延续仓库深蓝、主操作蓝、正文深色及系统中文/等宽编号字体。保存操作保持固定；新增控制放在独立扫描核对页、处理导出区、设置和仓库选择页。

扫描核对页先展示本次取景区域照片，支持双指放大/拖动及重置，再显示候选、最终编号与易混字符位置。替换按钮同时写明数字、大写或小写，避免只看字形仍分不清；一次只改明确选中的一位，不推断整串编号。照片和输入一起支持重建。正文可滚动，重新扫描/确认填入固定在底部，软键盘出现时仍能确认。

自动备份区直接显示最近生成时间、失败原因、立即备份及查看列表；每日开关集中在设置。列表按时间提供另存为、分享、恢复，恢复仍走原备份预览及确认。删除最后一个国家后可在仓库选择页访问，不需要先创建空国家。文案说明晨间备份保存当时状态，收工应立即备份并带走文件，分享面板打开不代表传输成功。

## 多行持续识别

扫描头部两项选择：单次识别/持续识别。持续模式中间是扩大取景框的相机，下面是一行一个编号的可滑动列表，底部保留补光与暂停/继续。使用现有蓝色主操作、青色编号框和等宽编号；数字行次对应相机标记与列表，具有实际定位作用。

相机中的标签带独立点击区域和连接到原编号位置的短线。标签最小高度48dp，纵向间距6dp；数量多于画面可排容量时保留全部原位置框，完整编号仍能在下方逐行点选。不开入场动画、不自动滚动列表，避免取景时干扰选择。

点击后先冻结对应照片，再进入原核对页；后台返回和模式切换清除旧行。盘点主页保存操作保持固定。
