# 0.2.2 变更说明

2026-10-20，基于已合并的0.2.1继续改进，版本号0.2.2 / versionCode 4，数据库schema4。

1. 同内容CSV防重复提醒，展示既往时间和仓库，允许明确继续。识别不依赖文件名，记录只在导入成功后保存。
2. 导入数量预览，区分正式件数、台数、待核查、重复作废及合并/新增明细，并显示预计本仓合计。
3. 重要操作保存本机恢复点并整批撤销；保留后来无关的新记录，冲突时停止。最近至多五次、96MiB容量预算，删除最后一个国家后仍能进入撤销。
4. 保存成功与重复SN使用不同反馈；震动默认开、声音默认关，分别设置和试听，重开保留。

86项本地检查及28项安卓检查通过，正式包已验证从0.2.1覆盖升级，以及导入后新增无关记录再整批撤销的JSON回读。

恢复点和CSV导入历史仅在本机；旧版导入记录不会自动补齐，导出备份不包含恢复点及导入历史。真实手机的相机、声音、振感仍按 [清单](真机试盘清单.md) 验证。
