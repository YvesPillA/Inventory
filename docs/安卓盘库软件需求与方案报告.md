# 安卓盘库软件：需求与实现说明

更新：2026年10月26日

应用版本：2.4.2 / versionCode 8

使用场景：本人携带一部安卓手机，在任意国家、不同仓库离线盘点。首次选择中文或 English，设置中可切换；语言仅影响界面与报告，不改写编号、名称、备注和历史数据。

## 一、操作流程

启动选择或创建国家和仓库，进入盘点、记录、处理、设置四页。三个业务页顶部简洁显示当前国家/仓库。日常切换与新建集中在启动页和设置；处理页的导入目标可以独立选择，且不会切换盘点仓库。

配件填写 BOM 和本次数量，输入或扫描 BOM 后下方查询本仓有效配件并显示是否已录入。整机填写 SN 前段和后段，BOM、PN 选填；PN 单框手输或扫描，多段横线保留原样，只有 SN 自动补中间横线。整机输入区可滚动，保存固定在底部，每台数量为 1。状态、备注放在“更多”弹窗，整机连续录入可保留 BOM。键盘展开时保持主要输入与保存可见。任务及库位不再出现在日常界面或 Excel/CSV 中，旧字段仅为旧数据库和完整备份保留兼容。

## 二、编号和重复规则

BOM 为 1～14 个英文字母或数字。整机 BOM、PN 可留空；PN 最多100位字母数字，可用多个横线连接非空分段。SN 为恰好一个英文横线连接的两段英文字母或数字，两段均非空、合计最多 14 位，含横线最多 15 位。前导零和大小写保留；只差大小写的近似 SN 手动录入时提示核对。

| 场景 | 配件 | 整机 |
| --- | --- | --- |
| 新增 | 同仓库、同 BOM、同状态时选择“添加到已有数量”或“新增条目” | 非空 SN 在所有国家、仓库的非作废记录中唯一；新增重复项经提示后转入作废 |
| 作废还原 | 有相同非作废配件时仍提供两种方式；相加后消耗原作废来源条目 | 被占用的 SN 继续保持作废 |
| CSV 导入 | 整批使用选定方式，状态不同分开 | 与现有记录及本批先前记录比较；全部重复型号与 SN 统一提示，重复新增项进入作废 |
| 仓库合并 | 两种方式统一作用于同 BOM、同状态的非作废配件；作废保持独立 | 移动已有整机，保持全局 SN 唯一，作废可保留重复 |
| JSON 备份合并 | 按记录 ID 合并，相同记录不重复计数 | 新增重复 SN 转入作废；同 ID 内容冲突取消整个合并 |

“添加到已有数量”选择最早的相同配件条目作为目标。来源说明保存在备注与合并审计中，已消耗条目不会继续留在作废页供再次还原。选择“新增条目”保留独立明细，两种方式的总数量相同。缺少 BOM 的待核查配件不能确定为同一型号，始终保留独立条目。

正常、损坏分状态计入确认数量；待核查不计入确认数量。待核查可缺失编号，但至少有一个编号或备注，已填写的编号仍须合规。作废全部不计数，允许重复 SN。

## 三、记录和仓库管理

记录按“正常”和“作废”两个页签分开。正常页指全部非作废记录，包含正常、损坏、待核查；支持搜索、筛选、修改、多选、长按勾选、批量作废。合并所选配件要求同仓库、同 BOM、同状态且至少两条；整机不可数量合并。

作废页支持还原、单条删除和清除全部作废。清除作废确认一次，清空正常确认两次，作用于当前仓库对应页的全部记录，不受搜索和筛选影响。删除同时移除关联修改历史。

设置可删除当前国家或仓库，连同记录和历史删除；两次确认均写明国家、仓库与记录数。删除国家包含该国家全部仓库。合并仅限同一国家：选择目标仓库和配件重复方式，两次确认写明来源与目标，合并后删除来源仓库。正常和作废记录均迁移，状态保持分开。

## 四、导入、导出与备份

“处理”内通过导入/导出切换操作。CSV 模板只有表头，按界面语言生成：`类型,BOM,SN,数量,状态,备注,PN` 或 `Type,BOM,SN,Quantity,Condition,Note,PN`，兼容没有 PN 的旧六列模板；接受两种语言及混合表头，类型和状态也支持中英文固定值。支持 UTF-8、标准引号、引号内换行、逗号及双引号；单文件最多 8 MiB、10000 条，字段最多 4000 字。格式错误报告行号，写入失败整批回滚。整机数量必须 1，配件为 1～1000000000。CSV 是库存添加，重复导入会再次添加；不是备份恢复。支持软件导出的中英文 XLSX、报告 CSV 及 CSV ZIP 直接导入所选仓库，只读明细并跳过汇总；完整 JSON 也可从同一入口选择，按原仓库检查并合并。编号列填写前设为文本。

导出保留当前仓库的 Excel 五页和 CSV ZIP；正常、损坏分别统计，待核查单列，作废只在完整备份中保存。完整 JSON 备份包含所有国家、仓库、现存记录、修改历史与旧版兼容字段；包含版本及 SHA256 完整性校验，最大 32 MiB。相同备份重复合并幂等；损坏或同 ID 内容冲突不会覆盖当前数据。旧备份仍可能重新恢复已经删除的条目。

## 五、离线扫描和升级

BOM/PN/SN 相机识别印刷数字、英文字母和横线；配件/整机备注单次识别多行文字、符号及换行，不套编号格式，识别后选择、核对再保存，SN 自动拆分两段；条形码和二维码解析仍暂缓。模型随 APK 打包，不声明联网权限。核对页显示同一取景区域的局部照片，可放大拖动；易混字符按位置提供显式替换，保留前导零、大小写和横线。照片仅暂存在私有缓存，正常退出/重扫清除，异常中断的过期照片下次扫描清理，不作为库存附件。相机不可用时可以手动填写。

Android 8.0 及以上，单机本地 SQLite，不需要服务器或运行时账号。正式包须使用原签名覆盖安装，数据库升级为 schema 5，新增 PN、来源和识别原文，旧记录默认空 PN；新备份写格式 v2 并兼容读取旧 v1，升级前先备份，不要先卸载。旧数据库 schema 2 升到 3 时，同一 SN 保留最近修改的非作废记录，其余转入作废并提示。

## 六、操作保障

CSV导入以解析内容计算指纹，提交时原子保存导入时间、文件名和仓库；再导入时提醒并允许明确继续。预览显示正式数量增量、重复作废、待核查、合并/新增条目及本仓预计数量。

重要操作前后保存完整校验快照并与操作一同提交；撤销时只退回所涉及且未被后续改动的行，保留无关新增。引用或名称冲突则整批停止，恢复整机遇到新SN占用则作废并汇总。最近至多五次恢复点，容量预算96MiB，自动清理最旧的点。恢复点及CSV导入历史不进入便携JSON备份；导入历史自0.2.2起在本机积累。

设置提供独立震动/声音开关与试用入口。保存成功与重复SN用不同节奏，声音默认关闭，设备缺少反馈能力不影响保存。

## 七、交付与验证边界

扫描支持独立持续模式，轮询当前相机预览的实际可见画面，扩大取景区域后离线OCR，按物理行和字元素定位当前字段的合规编号。两帧匹配稳定后显示；相同文字位于不同行保持独立身份。点击标记有最小触摸高度并避免重叠，拥挤时所有结果仍可由逐行列表选择。

只保持一个实时识别任务，不排队积累帧；预览确认为STREAMING才取图，缩放限制像素边长，旧结果及时过期。暂停或点选冻结与结果对应的照片；较慢结果自动暂停以保留对应关系。离开/切模式使旧回调失效，旧点击身份不重用。核对后仍需回到盘点保存，保持SN唯一等原库存规则。

默认开启每日完整备份，按手机当前时区每日首次使用时生成一份，启动/返回应用/写操作前检查，同日不重复自动生成。可手动立即备份最新状态，或在设置关闭自动生成。最近最多七份；先完成写入、同步、回读与完整性校验，再清理旧文件。失败不影响盘点，界面保留原因和重试入口。

处理、设置、仓库选择页提供时间列表、另存、分享和预览合并恢复；另存指定时间的快照，分享使用仅授予所选接收端读取权限的私有缓存副本。完整 JSON 格式及32MiB上限不变，保留所有库存、作废与修改历史；本机恢复点、CSV导入历史、偏好和临时照片不进入便携文件。备份仅在本机时仍会随卸载删除，带到电脑或新手机需用户另存或分享。
