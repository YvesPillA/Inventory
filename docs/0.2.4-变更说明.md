# 盘库助手 0.2.4

本版新增多行持续识别。versionCode 6，数据库保持 schema 4，使用原签名覆盖安装。

- “单次识别”“持续识别”独立切换，记住选择。持续模式取景框可容纳多行BOM或SN。
- 离线读取印刷字母、数字与横线，按物理行解析当前字段，不跨行拼接；相同编号在不同行各自保留。
- 稳定结果在相机上以可点击标签显示，对应原位置框与连线；标签保持最小点击高度和间距。
- 下方逐行列表保留所有结果，可滑动选择，处理密集标签。点选后只选当前这一条，进入原照片/字符核对页。
- 暂停冻结对应画面，继续清除旧行重新识别；较慢识别自动暂停。后台、模式切换使旧回调失效，过期/移走的点击不会替换成另一条编号。
- 只有确认填入后在盘点页保存才增加库存，整机SN仍全局唯一；扫描照片仍按原临时缓存规则清理。

真实标签准确率、反光、低光、长时间发热与耗电需用用户手机试扫，见[真机清单](真机试盘清单.md)。条形码/二维码内容解析保持暂缓。
