# 盘库助手 / FieldStock

[English](README.en.md)

离线安卓盘库工具，按国家和仓库管理配件与整机。支持中英文、标签文字扫描、Excel/CSV 报告和完整备份，无需账号或联网。

## 下载

当前版本 **2.4.4**，适用于 **Android 8.0 及以上**。

[正式安装包](artifacts/盘库助手-2.4.4.apk) · [源码](artifacts/盘库助手-2.4.4-源码.zip) · [校验值](artifacts/SHA256SUMS.txt)

重要数据请定期导出完整备份，并复制到其他设备。

## 主要功能

- **配件与整机盘点**：配件按 BOM 和数量录入，输入或扫描后查看已有记录；整机填写 SN 即可，BOM、PN 选填。
- **离线扫描**：识别 BOM、PN、SN 和多行备注，核对后保存。
- **中英互通**：首次选择语言，设置中可切换；中英文模板、报告和备份均可导入。
- **导入导出**：导出 Excel/CSV 报告及完整 JSON 备份，支持直接回导、重复检查和仓库合并。
- **上手与恢复**：内置新手教程、本机自动备份、操作恢复点和诊断日志。

## 使用与开发

首次选择语言并查看教程，新建国家、仓库后开始盘点。收工时导出报告与完整备份。
