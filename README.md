# 盘库助手 / FieldStock

[English](README.en.md)

供一人一部安卓手机使用的离线盘库软件。按国家和仓库管理配件、整机，支持印刷标签识别、中英文界面、Excel/CSV 导出和完整备份，无需账号或联网。

## 下载与安装

要求 **Android 8.0 或以上**。当前源码版本 **2.4.1**（versionCode 7）。

[2.4.1 正式安装包](artifacts/盘库助手-2.4.1.apk) · [源码](artifacts/盘库助手-2.4.1-源码.zip) · [SHA256 校验值](artifacts/SHA256SUMS.txt)

本包面向客户首次安装，使用新的固定发布签名；后续客户升级沿用该签名。与早期中文包签名不同，不能直接覆盖；已有库存请先导出完整 JSON 备份并复制到其他设备，**不要先卸载旧版**。

## 主要功能

- **盘点与管理**：配件按 BOM 和数量录入；整机按 BOM、SN 逐台录入。支持多国家、多仓库、修改、作废、还原、批量操作和同国家仓库合并。
- **离线扫描**：单次或多行持续识别印刷编号，支持照片放大、易混字符核对；确认填入后手动保存。暂不解析条形码或二维码。
- **中英互通**：首次选择语言，设置中可切换；界面、报告和模板随语言显示，中英文 CSV 均可导入。编号、名称和备注保留原文。
- **导出与恢复**：当前仓库导出 Excel/CSV，全部仓库保存完整 JSON 备份。每日自动备份最多 7 份，重要操作可通过最近最多 5 个本机恢复点整批撤销。
- **数量核对**：导入前预览数量，重复 CSV 提醒；正常、损坏分开统计，待核查和作废不计入确认数量。

## 开始使用

1. 选择中文或 English，新建或选择国家、仓库后进入盘点。
2. 配件填写或扫描 BOM，再输入本次数量；整机填写 BOM、SN，每台数量为 1。状态和备注在“更多”中填写。
3. 保存后在“记录”中检查或修改。收工时到“处理 → 导出”保存报告和完整备份，并把文件复制到其他设备。

BOM 为 1～14 位英文字母或数字；SN 为两段英文字母或数字，以 `-` 连接，两段合计最多 14 位。保留前导零与大小写，非空整机 SN 在全库非作废记录中唯一。

## 导入与导出

在“处理 → 导入”下载当前语言的标准模板。仅支持 **UTF-8 CSV**，接受中文、英文或混合表头，列顺序如下；英文表头和固定取值不区分大小写。

| 中文 / English | 填写规则 |
| --- | --- |
| 类型 / Type | 配件 / Part / Parts；整机 / Machine |
| BOM | 英文字母或数字，按原编号保留 |
| SN | 配件留空；整机填写完整的 `前段-后段` |
| 数量 / Quantity | 正整数；整机必须为 1 |
| 状态 / Condition | 正常 / Normal；损坏 / Damaged；待核查 / Pending verification / Pending |
| 备注 / Note | 保留原文；待核查缺号时至少有一个编号或备注 |

在 Excel 填写前将 BOM、SN 列设为文本，再保存为 CSV UTF-8。单文件最多 8 MiB、10000 条，错误会显示行号并取消整批。CSV 用于追加库存，确认重复导入会再次增加数量。

报告 Excel 包含说明、配件明细/汇总、整机明细和待核查；CSV ZIP 包含三类报告及说明。**报告 CSV、XLSX 和 ZIP 不能当作标准模板导入**；换机恢复用完整 JSON 备份，保留全部仓库、作废记录和修改历史。

本机自动备份及恢复点随卸载删除；恢复点、CSV 导入历史、偏好和扫描照片不进入便携 JSON 备份。
