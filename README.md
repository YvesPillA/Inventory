# 盘库助手 / FieldStock

[English](README.en.md)

供一人一部安卓手机使用的离线盘库软件。按国家和仓库管理配件、整机，支持印刷标签识别、中英文界面、Excel/CSV 导入导出和完整备份，无需账号或联网。

## 下载与安装

要求 **Android 8.0 或以上**。当前为 **2.4.4 热修版**（versionCode 10，版本号保持不变），包含库存合并、文件往返、扫描和诊断的审查修复。

[2.4.4 正式安装包](artifacts/盘库助手-2.4.4.apk) · [源码](artifacts/盘库助手-2.4.4-源码.zip) · [SHA256 校验值](artifacts/SHA256SUMS.txt)

沿用 2.4.1 客户版的固定发布签名，可覆盖客户版 2.4.1 / 2.4.2 / 2.4.3 升级。与早期中文包签名不同，不能直接覆盖；已有库存请先导出完整 JSON 备份并复制到其他设备，**不要先卸载旧版**。

## 主要功能

- **盘点与管理**：配件按 BOM 和数量录入，手输或扫描后即时查看本仓已有记录；整机按 SN 逐台录入，BOM、PN 选填。支持多国家、多仓库、修改、作废、还原、批量操作和同国家仓库合并。
- **离线扫描**：BOM、PN、SN 支持单次或多行持续识别；两类盘点的备注可扫描多行文字、符号和换行，支持照片放大、易混字符核对；确认填入后手动保存。暂不解析条形码或二维码。
- **中英互通**：首次选择语言，设置中可切换；界面、报告和模板随语言显示，中英文模板和导出报告均可交叉导入。编号、名称和备注保留原文。
- **导出与恢复**：当前仓库导出 Excel/CSV，全部仓库保存完整 JSON 备份。每日自动备份最多 7 份，重要操作可通过最近最多 5 个本机恢复点整批撤销。
- **排查问题**：保留本机操作、文件读写、异常与卡顿日志；开发模式可筛选、导出和分享诊断包。
- **数量核对**：导入前预览数量，重复表格内容提醒；正常、损坏分开统计，待核查和作废不计入确认数量。

## 开始使用

1. 选择中文或 English，新建或选择国家、仓库后进入盘点。
2. 配件填写或扫描 BOM，再输入本次数量；整机只需填写 SN，BOM、PN 可填写或扫描，每台数量为 1。状态和可扫描的备注在“更多”中填写。
3. 保存后在“记录”中检查或修改。收工时到“处理 → 导出”保存报告和完整备份，并把文件复制到其他设备。

BOM 为 1～14 位英文字母或数字；PN 为最多 100 位字母数字，可用多个 `-` 连接非空分段；SN 为两段英文字母或数字，以 `-` 连接，两段合计最多 14 位。保留前导零与大小写，非空整机 SN 在全库非作废记录中唯一。

## 导入与导出

选完文件后会显示读取进度，并自动定位到预览确认区；后台备份或初始化忙时会排队处理。

在“处理 → 导入”直接选择导出的 **Excel、CSV 压缩包、完整 JSON 备份**或标准 CSV。中英文文件不受当前界面语言限制。Excel/CSV 导入所选目标仓库；JSON 保留原国家、仓库、记录及修改历史，预览后检查并合并。

JSON 遇到同名国家时，可将备份仓库加入现有国家；同名仓库可合并或改名加入。合并时，同 BOM、同状态的配件可选择“新增条目”或“添加到已有数量”。相同备份再次导入不会重复加数量；后续合并或迁移仍保留已处理来源及历史。位置改名后可确认使用现有位置，重要操作可从本机恢复点撤销。

也可下载当前语言的 **UTF-8 CSV** 模板，接受中文、英文或混合表头，列顺序如下；英文表头和固定取值不区分大小写。

| 中文 / English | 填写规则 |
| --- | --- |
| 类型 / Type | 配件 / Part / Parts；整机 / Machine |
| BOM | 字母数字，整机可留空 |
| SN | 配件留空；整机填写完整的 `前段-后段` |
| 数量 / Quantity | 正整数；整机必须为 1 |
| 状态 / Condition | 正常 / Normal；损坏 / Damaged；待核查 / Pending verification / Pending |
| 备注 / Note | 保留原文及换行；待核查缺号时至少有一个编号或备注 |
| PN | 整机选填；字母数字及多段横线，配件留空 |

旧版没有 PN 的六列 CSV 仍可导入，新模板在末列增加 PN。在 Excel 填写前将 BOM、PN、SN 列设为文本，再保存为 CSV UTF-8。单文件最多 8 MiB、10000 条，错误会显示行号并取消整批。CSV 用于追加库存，确认重复导入会再次增加数量。

报告 Excel 包含说明、配件明细/汇总、整机明细和待核查；CSV ZIP 包含三类报告及说明。**报告可直接导入**，只读取明细，跳过说明及汇总；重复的报告记录 ID 会取消整批。兼容没有 PN 的旧报告，保留编号大小写、前导零及备注空格和换行。

新报告 CSV 增加“备注转义 / Note escaped”标记，回导时还原用于防止表格公式执行的安全前缀；旧版无标记 CSV 保留文件中的原文。标准导入模板不变。完整迁移优先使用 JSON：最多 32 MiB，相同来源跳过，无法匹配的同 ID 内容冲突整批取消，新增重复 SN 转作废。

2.4.4 可读取旧备份；新备份格式 v2 保存 PN，需用 2.4.2 或以后兼容版本恢复。本机自动备份及恢复点随卸载删除；恢复点、CSV 导入历史、偏好和扫描照片不进入便携 JSON 备份。

## 开发与说明

Kotlin、Jetpack Compose、SQLite、CameraX、随包 ML Kit OCR。构建需要 JDK 17、Android SDK 35：

```powershell
.\gradlew.bat assembleDebug testDebugUnitTest lintDebug
```
