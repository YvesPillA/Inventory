# 盘库助手 0.2.3

一人一部安卓手机使用的离线盘库软件。支持自由添加国家与仓库、配件 BOM 与数量、整机 BOM/SN、标签文字识别、Excel/CSV 导出及完整备份。

## 安装与升级

安装文件：[盘库助手-0.2.3.apk](artifacts/盘库助手-0.2.3.apk)。源代码：[盘库助手-0.2.3-源码.zip](artifacts/盘库助手-0.2.3-源码.zip)。要求 Android 8.0 或以上。

首次安装：把 APK 复制到手机，点开并按系统提示允许当前文件管理器安装应用。

从旧版升级：先保存完整备份并复制到电脑，再直接安装 0.2.3 APK，以同一签名覆盖升级，**不要先卸载**。升级会保留现有数据；0.2.2 升级时数据库仍为 schema 4。更早版本如果在不同任务下保存过相同 SN，数据库升级会保留最近修改的一条为非作废记录，其余移到作废页并保留完整修改历史，界面会提示处理数量。

## 0.2.3 新增

- OCR 核对页显示本次取景区域照片，可双指放大、拖动与重置。0/O/o、1/I/i/l、8/B/b 按位置提供替换选项，只有点选才修改一位；前导零、大小写和 SN 横线保留。
- 照片与最终输入在扫描页重建后仍对应，确认返回原始识别文字；正常退出或重扫清除临时照片。照片不作为库存附件，也不进入备份。
- 每日自动完整备份默认开启，按手机当前时区，在每天首次使用时保存当时的全部库存。启动、返回应用及写操作前检查；同一天重开不会重复生成，可随时“立即备份”保存最新状态。
- 最多保留最近 7 份本机完整备份，写入并回读校验成功后才清理旧文件。备份失败显示具体原因，盘点仍可继续；支持关闭每日自动备份。
- 处理、设置及仓库选择页可查看备份时间、另存为、分享或预览合并恢复。删除最后一个国家后仍能访问。另存选中时间的备份，适合复制到电脑或带到新手机。

本机备份随卸载删除；收工点“立即备份”并另存或分享，核对接收端文件。JSON 格式与旧版兼容，范围仍是全部库存、作废和修改历史，不包含本机恢复点、CSV 导入历史、提示偏好或扫描照片。

## 0.2.2 新增

- 同内容 CSV 再次导入会列出既往时间和仓库，确认“仍要重复导入”后才继续；改名、UTF-8 BOM 和行结束符变化不影响识别。
- 导入前显示正式配件增加件数、整机台数、待核查行、重复作废数、合并/新增条目和导入后本仓数量。
- 导入、仓库合并、记录合并、作废还原、批量作废、清空及删除前自动保存恢复点；设置或仓库选择页可整批撤销，保留后来无关的新记录，相关内容已改动时停止并提示。
- 保存成功短震动，重复 SN 使用不同反馈；设置可分别开关震动、声音并试听。声音默认关闭。

恢复点仅在本机保留，最多五次且受容量限制；CSV 导入记录从0.2.2开始积累，旧版导入及换机前记录不能自动识别。完整JSON备份不包含恢复点、CSV导入历史或声音偏好，收工仍需导出并复制备份。

## 开始盘点

1. 启动时选择或新建国家和仓库，点击“进入仓库”。进入后底部为“盘点、记录、处理、设置”。
2. 三个业务页面顶部只显示一行当前国家/仓库。切换或新建国家、仓库请到“设置”；有未保存输入时会先提示处理。
3. 配件填写或扫描 BOM，再输入本次数量。整机填写或扫描 BOM、SN；手动 SN 分为前段、后段，中间横线自动补齐，每台一条记录。
4. 状态和备注放在“更多”弹窗。标签缺号时选“待核查”，至少保留一个编号或一条备注。待核查不计入已确认数量。
5. 在“记录”的“正常”页修改或作废；“作废”页可还原或删除。“正常”页包含正常、损坏、待核查三种状态。
6. 每天结束后在“处理 → 导出”保存当前仓库的 Excel 和所有仓库的完整备份，再复制到电脑或其他位置。

详细步骤见 [操作说明](docs/操作说明.md)，当前规则见 [需求与实现说明](docs/安卓盘库软件需求与方案报告.md)，检查结果见 [验收记录](docs/验收记录.md)。

## 编号、统计与删除规则

- BOM：1～14 个英文字母或数字，前导零、大小写保留。
- SN：两段英文字母或数字；不计中间自动补齐的 `-` 最多 14 位，含横线最多 15 位。整机数量固定为 1。
- 完全相同的非空整机 SN 在所有国家、所有仓库的非作废记录中唯一。只差大小写会提示核对，系统保留原样。
- 同仓库、同 BOM、同状态配件重复时，可选择“添加到已有数量”或“新增条目”；不同状态分开保存。还原、导入及仓库合并遵循同一规则。修改原数量请到记录页操作。
- 正常、损坏为已确认状态；待核查独立导出；作废不计数量。日常界面和 Excel/CSV 不再使用任务、库位，历史字段仅在数据库和完整备份中保留兼容。
- 作废允许保留重复 SN；还原时 SN 已被非作废记录占用，会保持作废并提示冲突。
- 单条删除、清除当前仓库全部作废记录各确认一次；清空当前仓库“正常”页记录确认两次。批量清空包含该页全部类别和状态，不受当前搜索或筛选影响，只作用于当前仓库。
- 删除同时移除当前库存中的相关修改历史；最近的重要操作可在设置整批撤销，以前保存的备份仍可能含这些记录，重新导入可能再次恢复它们。

## 国家、仓库和批量记录管理

设置可删除当前国家或仓库，连同全部记录及修改历史删除，两次确认均写明目标。可将当前仓库并入同国家的另一仓库，选择配件重复处理方式，两次确认后迁移正常及作废记录并删除来源仓库。

记录的正常页可点“多选”或长按条目，勾选后批量作废；至少两条同 BOM、同状态配件可合并数量，整机不可合并。合并消耗来源条目，保留来源说明，避免重复计数。

## 导出、备份与隐私

Excel 和 CSV 只导出当前仓库全部历史有效记录。配件按仓库、BOM、状态汇总，不按旧任务分开。Excel 包含盘点说明、配件明细、配件汇总、整机明细、待核查五页，编号列使用文本单元格。CSV ZIP 含配件、整机、待核查三份 CSV 和说明；导入 Excel 时把 BOM/SN 列设为文本。

完整 JSON 备份包含所有国家和仓库、现存记录（含待核查和作废）、修改历史及旧版兼容字段，已删除的记录不在新备份中。备份带格式版本、32 MiB 大小限制和 SHA256 完整性校验；校验用于发现损坏，不是加密。恢复采用事务合并，相同记录不重复增加；同 ID 内容冲突会取消整个合并。新增整机 SN 与已有记录或本批记录重复时，新增重复记录转入作废，统一提示 BOM 和 SN。

记录和审计保存在手机 SQLite 数据库。OCR 模型随 APK 打包，不要求登录或联网；安装包不声明联网权限。扫描的是印刷编号文字，条形码/二维码解析暂缓。扫描核对照片暂存应用私有缓存，正常退出或重扫即清除；异常中断的过期照片在下次扫描时清理，不作为库存附件或备份内容。拒绝相机权限仍可手动盘点。

卸载会删除应用内记录。更换手机前先导出并复制完整备份；升级请直接覆盖安装。

## 标准 CSV 模板与批量导入

在“处理 → 导入”下载标准模板，选择国家和仓库作为导入目标，选择配件重复处理方式，再读取文件并确认导入。导入目标不改变当前盘点仓库。只支持 UTF-8 CSV，表头严格为 `类型,BOM,SN,数量,状态,备注`；模板只有表头，无示例库存，也可直接下载 [标准导入模板](artifacts/盘库标准导入模板.csv)。XLSX/Excel 工作簿和日常导出的明细 CSV 不能直接作为标准模板导入。

填写 BOM/SN 前在 Excel 中把列设为文本，保存为“CSV UTF-8（逗号分隔）”，避免前导零丢失或编号转成科学计数法。配件 SN 留空、数量填写正整数；整机数量必须 1，SN 填完整前后两段及横线；状态填写正常、损坏或待核查。备注支持正确加引号的逗号、换行和双引号。文件上限 8 MiB、10000 条数据，格式错误显示行号并取消本批导入。

手动新增及批量导入中的重复整机 SN 保存在作废页，批量操作统一提示 BOM、SN 和数量；非重复记录正常导入。导入是追加记录，重复导入同一 CSV 会再次追加；需要恢复原手机数据时使用完整 JSON 备份。

## 开发与构建

技术：Kotlin、Jetpack Compose、SQLiteOpenHelper（数据库 schema 4）、CameraX、随包 ML Kit 拉丁文字识别。没有后端或运行时账号依赖。

在已配置 Android SDK 35 与 JDK 17 的环境可用：

```powershell
.\gradlew.bat assembleDebug testDebugUnitTest lintDebug
```

本项目提供工作区内工具安装脚本（下载官方工具、校验 SHA256，不修改全局 PATH）：

```powershell
.\tools\setup-android.ps1
.\tools\build.ps1
```

`local.properties`、`.toolchain/` 不应提交；下载与缓存位于 `.toolchain/`。工具版本固定为 AGP 8.7.3、Gradle 8.9、Kotlin 2.0.21、SDK 35。真机/模拟器接入后可运行 `connectedDebugAndroidTest`；生成正式包可运行 `assembleRelease`。

本机签名版本使用 `.signing/fieldstock-release.jks` 和 `.signing/signing.properties`；两者未打包进源码分发。请私下备份签名文件，后续覆盖升级必须使用同一签名。其他开发机没有这些文件时，`assembleRelease` 生成未签名产物，需要自行配置签名。

## 使用前验证

该版范围为单机离线盘点，不含多人同步、账面库存差异对比或条码/二维码解析。真实手机相机与真实标签尚未完成现场验证；模拟器合成标签 OCR 测试不能代替实机验证。出发前请开飞行模式试盘典型标签，检查前导零、长 SN、反光和模糊情况，并完成导出及备份回读演练。
